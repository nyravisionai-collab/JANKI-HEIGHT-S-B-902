# generated_files — કામ દરમિયાન બનેલી ફાઈલો

આ ફોલ્ડરમાં કોટેશન બનાવવાની પ્રક્રિયા દરમિયાન જનરેટ થયેલી બધી અર્થપૂર્ણ ફાઈલો છે.
(ખાલી/ટેસ્ટિંગ રેન્ડર ઈમેજો, જેમાં કંઈ દેખાતું ન હતું, તે છોડી દેવામાં આવી છે.)

## ફાઈલોની યાદી

| ફાઈલ | વર્ણન |
|---|---|
| `dxf/plan.dxf` | મૂળ DWG ફાઈલ (`BULD-B 901_JANKI HEIGHTS_electric plan.dwg`) નું DXF કન્વર્ઝન (LibreDWG એન્જિનથી). આમાંથી જ આખું ઈલેક્ટ્રિકલ લેઆઉટ વાંચીને પોઈન્ટ ગણવામાં આવ્યા હતા. |
| `images/electrical_plan_overview.png` | ડ્રોઈંગમાંથી કાઢેલું ફ્લેટ 901 ના ત્રણેય શીટ્સ (Ceiling Plan, Light Dimension Layout, Electric Wiring Layout) + લિજન્ડનું સંયુક્ત ચિત્ર. આ જ ચિત્ર કોટેશનના Annexure-A માં વપરાયું છે. |
| `scripts/render_plan.py` | કસ્ટમ રેન્ડરિંગ સ્ક્રિપ્ટ — DXF માંથી ઈલેક્ટ્રિકલ લેઆઉટની સ્પષ્ટ ઈમેજ બનાવે છે (લેયર પ્રમાણે રંગ: ઈલેક્ટ્રિકલ લાલ, દિવાલો કાળી વગેરે). |
| `scripts/make_quotation.py` | કોટેશન બનાવવાની સ્ક્રિપ્ટ — પોઈન્ટ શેડ્યૂલ, BOQ, શરતો અને Annexure સાથે `GE_Quotation_JankiHeights_B901_Flat901.docx` જનરેટ કરે છે. |

## નોંધ

- રેટ/ક્વોન્ટિટી બદલવા હોય તો `scripts/make_quotation.py` માં `items` યાદી સુધારીને ફરી ચલાવી શકાય.
- નવી ઈમેજ જોઈએ તો `scripts/render_plan.py` ફરી ચલાવી શકાય (જરૂર પડે તો તેમાંની X/Y મર્યાદા બદલીને).
- બંને સ્ક્રિપ્ટને `ezdxf` (અને ઈમેજ માટે `matplotlib`) પાયથોન લાઇબ્રેરીની જરૂર છે.
